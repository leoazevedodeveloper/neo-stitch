Do HTML ao GLB animado

Escada do Movimento

Os dez degraus de tecnologia para dar vida a uma interface na web, do mais simples ao mais complexo. Cada degrau tem um exemplo ao vivo: mova o cursor e clique nos palcos. As etiquetas coloridas marcam os conceitos que não são um degrau, e sim ferramentas que aparecem em vários deles ao mesmo tempo.

Conceitos que atravessam os degraus

GSAP não é um degrau: é o maestro que anima propriedades em qualquer camada (CSS, atributos de SVG, uniforms de shader, rotação de um objeto 3D). O mesmo vale para cursor, ruído e bloom. Cada ponto abaixo é um lugar onde o conceito aparece em ação nesta página.

Degrau 1

HTML + CSS

Layout, texto e efeitos que o navegador desenha sozinho. Nenhuma linha de JavaScript neste palco: a borda que gira, o pulso do status e o equalizador são animações de CSS.

Faz bem
cards, texto, transições, hover, brilhos, gradientes, desfoques
Para
em qualquer forma que não seja retângulo, texto ou gradiente
Ferramentas
@keyframes, transition, @property, conic-gradient

Degrau 2

CSS + JS (coreografia)

O mesmo HTML, agora regido por uma linha do tempo: os agentes acendem em sequência, o número conta e o círculo segue o cursor com inércia.

Faz bem
sequências, reações a scroll e cursor, contadores, entradas encadeadas
Para
no que o CSS consegue desenhar
Ferramentas
GSAP (timeline, stagger, quickTo), ScrollTrigger, Lenis
CPU0%
o círculo segue o cursor
Degrau 3

SVG

Vetores animados: o arco de agentes, os anéis tracejados que giram e a luz que "enche" o conector até o nó. O título ondula com um filtro de turbulência.

Faz bem
arcos, conectores, traços que se desenham, ícones, ondulação por filtro
Para
em volume e em milhares de elementos
Ferramentas
SVG + GSAP (stroke-dashoffset), feTurbulence; Lottie e Rive para vetores vindos de editores
passe o mouse nos nós
Degrau 4

Canvas 2D

Pixels desenhados por código, quadro a quadro: 1.400 partículas seguem um campo de fluxo, deixam rastro e fogem do cursor com velocidade e atrito.

Faz bem
centenas a poucos milhares de partículas, ondas, gráficos vivos
Para
na CPU: dezenas de milhares ficam lentas; tudo é plano
Ferramentas
Canvas API, p5.js
mova o cursor pelas partículas
Degrau 5

Shader de tela

A GPU calcula a cor de cada pixel ao mesmo tempo: uma aurora em ruído fractal com domain warp, iluminada onde o cursor está. É o tipo de fundo vivo do New Era.

Faz bem
fundos vivos, gradientes que fluem, distorção de imagem, ruído
Para
em objetos e profundidade: é um retângulo pintado
Ferramentas
WebGL com fragment shader, OGL, estilo Shadertoy
a luz segue o cursor
Degrau 6

Cena 3D procedural

Objetos 3D montados com formas prontas: um núcleo, anéis e luas em órbita, luz de verdade e bloom. A câmera inclina com o cursor; o clique dispara um pulso.

Faz bem
objetos geométricos, iluminação, profundidade, câmera
Para
em objetos detalhados ou orgânicos
Ferramentas
Three.js com materiais prontos, UnrealBloomPass
mova o cursor · clique para pulsar
Degrau 7

3D com shaders próprios

60 mil partículas na GPU, deformadas por ruído no vertex shader, trocando de forma (esfera, nó, X) a cada clique, dentro de uma grade em wireframe que acende perto do cursor.

Faz bem
dezenas a centenas de milhares de partículas, deformação, troca de forma
Para
na física: cada partícula não "lembra" de onde veio
Ferramentas
Three.js + ShaderMaterial, amostragem de pontos de uma forma
New Era e Auralis moram aqui. O New Era é a nuvem de pontos com ruído + o fundo do degrau 5. O Auralis é a troca de forma + a grade que acende com o cursor (no site, a troca vem do scroll).
mova o cursor · clique para trocar a forma
Degrau 8

Simulação na GPU (GPGPU)

16 mil partículas com posição e velocidade guardadas em texturas, atualizadas pela GPU a cada quadro: seguem um campo de fluxo (curl noise) e são atraídas pelo cursor com inércia de verdade.

Faz bem
física: inércia, campos de fluxo, colisão com o cursor, fluidos
Para
na complexidade de escrever e ajustar
Ferramentas
Three.js GPUComputationRenderer, WebGPU compute
Quando o Auralis vira degrau 8: se as partículas tiverem inércia e reagirem ao cursor com física, como aqui, em vez de só interpolar entre formas.
segure o clique para atrair · solte para dispersar
Degrau 9

Modelo 3D (GLB)

Um arquivo 3D com malhas, materiais e hierarquia, modelado fora do navegador (aqui, no Blender, por script) e carregado inteiro. Gira em qualquer ângulo, porque existe de verdade por trás.

Faz bem
objetos e personagens detalhados, material realista, qualquer ângulo
Para
no custo de modelar (ou gerar por image-to-3D) e ajustar
Ferramentas
Blender, image-to-3D (Hunyuan3D, TRELLIS, Tripo), GLTFLoader
arraste para girar
Degrau 10

GLB animado

O mesmo arquivo, agora com o que faz um personagem: a cabeça é um nó próprio que olha para o cursor, os olhos têm expressões (morph targets) e há animações prontas no arquivo (flutuar, acenar). Falar move os olhos com a voz.

Faz bem
olhar, expressões, falar sincronizado, gestos, personagens
Para
no trabalho de rig: nós, pesos, morphs e animações
Ferramentas
Blender, Mixamo (humanoides), AnimationMixer, Web Audio
ele olha para o cursor
